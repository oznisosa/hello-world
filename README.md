# hello-world
Juego de escape del colegio
==========================

Este repositorio contiene un pequeño juego de consola escrito en Python. Controlas a Shavy, un estudiante que intenta escapar del colegio mientras evita a los monstruos que lo persiguen, incluido el implacable Hilario.

## Requisitos

- Python 3.10 o superior.

## Cómo jugar

1. Ejecuta el juego con:

   ```bash
   python game.py
   ```

2. Usa las teclas `W`, `A`, `S` y `D` para mover a Shavy en cada turno.
3. Llega a la salida marcada con `⛩` antes de que alguno de los monstruos alcance a Shavy.
